# VB6 Form Resizer

A professional VB6 UserControl that automatically resizes forms, controls and fonts when the application window size changes.

## Features

- Automatic form scaling
- Control resizing
- Font scaling
- Supports Frames, SSTab, PictureBox
- Easy integration
- No external DLL required

## Why Use This?

Many legacy Visual Basic 6 applications do not resize properly on modern displays.

This project provides a simple solution for automatic resizing and DPI-aware scaling in VB6 applications.
